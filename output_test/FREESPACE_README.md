# Free Space 400 MHz - Direct Wave Reference

## Purpose
This configuration creates a free space (air-only) simulation for the GSSI 400 MHz antenna used in the Puerto-Limache GPR survey. It captures the **direct antenna pulse** in free space for:

- **Waveform scaling**: Measure peak-to-peak amplitude to scale synthetic data to real A/D converter counts
- **Direct wave characterization**: Understand the direct pulse shape and duration (expected ~4.5 ns for 400 MHz)
- **System calibration**: Validate antenna model against real-world Puerto-Limache data
- **Baseline comparison**: Compare synthetic direct wave with real GSSI traces

## Configuration Details

| Parameter | Value | Notes |
|-----------|-------|-------|
| **Antenna** | GSSI 400 MHz | Hertzian dipole equivalent |
| **Center Frequency** | 400 MHz | Matches Puerto-Limache acquisition |
| **Domain** | 0.5m × 0.5m × 0.5m | Large enough for free space direct wave |
| **Grid Resolution** | 3mm (dx=dy=dz) | Coarse grid suitable for free space |
| **Time Window** | 20 ns | Captures direct pulse + early reflections |
| **Antenna Height** | 0.1m above air | Simulates ~10cm standoff from surface |
| **Receiver Offset** | 0.05m (bi-static) | 5cm horizontal separation |
| **PML Layers** | 10 cells | Absorbs outgoing waves |

## Expected Output

When run with gprMax, the simulation will produce:
- **Direct pulse**: Sharp peak at ~0.67 ns (time to travel 0.1m in air at c)
- **Ringing**: ~±2.5 ns duration (inverse of 400 MHz period)
- **Peak-to-peak amplitude**: Reference value in V/m (physical units from gprMax)
- **Total samples**: ~644 samples @ 32.1 GHz (matching synthetic dataset sampling)

## How to Run

### Option 1: Run with gprMax (requires installation)
```bash
gprMax output_test/freespace_400mhz.in

This generates: `freespace_400mhz.out`

docker run gprmax/gprmax:latest freespace_400mhz.in
```

## Waveform Scaling (Real vs. Synthetic)

Compare the real Puerto-Limache direct wave with synthetic:

```python
# Real GSSI data (Puerto-Limache)
real_peak = np.max(np.abs(traces_real))  # A/D converter counts

# Synthetic free space
synthetic_peak = peak_amplitude  # V/m

# Scaling factor
scale_factor = real_peak / synthetic_peak

# Apply to all synthetic traces
traces_synthetic_scaled = traces_synthetic * scale_factor
```

After scaling, synthetic traces can be directly compared with real data for:
- Feature distribution matching
- Sim→real domain adaptation
- Amplitude-dependent algorithm validation
