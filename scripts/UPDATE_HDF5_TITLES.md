# HDF5 Title Updater

Updates the title attribute in gprMax HDF5 output files (`.out`) to match the FI_class from their corresponding input files (`.in`).

## Purpose

When you generate synthetic data with `synthetic_data_generator.py`, the FI_class (e.g., "CL", "MF", "F", "HF") is written to the `#title` field in the `.in` files. After running gprMax simulations, you'll have `.out` (HDF5) files. This script updates the HDF5 title attribute to match the FI_class from the input files.

## Location
`scripts/update_hdf5_titles.py`

## Usage

### Basic Usage
```bash
python scripts/update_hdf5_titles.py <folder_path>
```

### Examples

**1. Dry run (preview changes without modifying files):**
```bash
python scripts/update_hdf5_titles.py synthetic_inputs/ --dry-run
```

**2. Update titles in a folder:**
```bash
python scripts/update_hdf5_titles.py synthetic_inputs/
```

**3. Update titles in output folder:**
```bash
python scripts/update_hdf5_titles.py output/
```

## How It Works

1. **Scans folder** for all `.out` (HDF5) files
2. **For each `.out` file**, finds the matching `.in` file (same name, different extension)
3. **Reads the `#title`** field from the `.in` file
4. **Updates the HDF5 attribute** `title` in the `.out` file

## Requirements

The script expects:
- Pairs of files with the same basename (e.g., `s0000_unif.in` and `s0000_unif.out`)
- Input files generated by `synthetic_data_generator.py` with `#title: <FI_class>` format

## Example Workflow

```bash
# 1. Generate synthetic input files
python scripts/test_data_generator.py

# 2. Run gprMax simulations (creates .out files)
# (use gprMax to process the .in files)

# 3. Update HDF5 titles to match FI_class
python scripts/update_hdf5_titles.py synthetic_inputs/
```
