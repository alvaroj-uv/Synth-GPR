# Ground Penetrating Radar: Multi-components AVO and AVA

## Pros and Cons of GPR MULTI-AZIMUTH surveys

1. By applying antenna arrays it is possible to collect multi azimuth data during the same survey path. If series of common offset surveys are “simultaneously” collected then ALL the linear targets can be located → very helpful for pipes and technological networks location.
2. Possible experimental problems can make difficult the interpretation (antennas directivity, target within not homogeneous and isotropic materials, ...).
3. The maximum accuracy is compulsory during data acquisition (positioning, combined rotation of the antennas, effective antennas orientation, ...).
4. The approach can be time consuming and can be essential to collect data in several different positions, but it can be preferable respect to 2.5D dense surveys.
